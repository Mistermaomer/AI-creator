# קריינות — ElevenLabs

משפט הקריינות: "אל תפסידו, היום יריד הפרחים במתחם חדר האוכל, מחכים לכם".
קריינית מקצועית, חמה ואנרגטית. ~5–6 שניות.

## הבעיה שהניקוד פותר

בעברית ללא ניקוד המנוע מנחש הגייה, ובמשפט הזה יש ארבע מילים בסיכון:

| מילה | הגייה שגויה נפוצה | הניקוד המתקן |
|---|---|---|
| האוכל | הָאוֹכֵל (מי שאוכל) | הָאֹכֶל |
| מתחם | מְתַחֵם (פועל) | מִתְחַם |
| יריד | יְרִידָה | יָרִיד |
| הפרחים | הַפּוֹרְחִים | הַפְּרָחִים |

## גרסה A — Eleven v3 (מומלץ, תומך בתגיות)

```
[warm] [cheerfully] אַל תַּפְסִידוּ!

הַיּוֹם — יְרִיד הַפְּרָחִים, בְּמִתְחַם חֲדַר הָאֹכֶל.

[smiling] מְחַכִּים לָכֶם!
```

## גרסה B — Multilingual v2 (בלי תגיות!)

ב-v2 תגיות בסוגריים מרובעים **מוקראות בקול**. להשתמש רק בפיסוק ובהפסקות:

```
אַל תַּפְסִידוּ! <break time="0.4s" /> הַיּוֹם, יְרִיד הַפְּרָחִים <break time="0.2s" /> בְּמִתְחַם חֲדַר הָאֹכֶל. <break time="0.45s" /> מְחַכִּים לָכֶם!
```

## הגדרות קול

| פרמטר | ערך | למה |
|---|---|---|
| Stability | 40–50% | נמוך = יותר רגש וגיוון. מעל 70% נשמע שטוח ומכני |
| Similarity | 80% | שומר על מאפייני הקול שלך |
| Style | 0–25% | מעל 30% מתחיל להכניס ארטיפקטים בעברית |
| Speaker boost | פעיל | |
| Speed | 0.95 | קצת יותר איטי = נשמע מקצועי ובטוח |

## טיפים

- **הרץ 3–4 גרסאות** ובחר. ElevenLabs מגריל כל פעם אחרת, וההבדל בין טייק ראשון לרביעי ענק.
- **מבנה שלושת הביטים:** קריאה ("אל תפסידו!") ← מידע (איפה ומתי) ← סגירה חמה ("מחכים לכם"). ההפסקות בין הביטים הן מה שנותן את תחושת הקריינות המקצועית.
- **אם עדיין נשמע מכני:** הורד את ה-Stability ל-30% ונסה שוב.
- **אופציה יצירתית:** אם רוצים שזה יישמע כמו כריזה במתקן — לסנן ב-EQ (חיתוך מתחת ל-300Hz ומעל 3.5kHz) ולהוסיף ריוורב קצר. מתאים במיוחד אם הקריינות מתנגנת בסצנת החדר הנקי או הקמפוס.
