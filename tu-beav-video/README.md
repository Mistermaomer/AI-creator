# סרטון ט"ו באב — "הבחור מהתעשייה האווירית"

סרטון קומי קצר (~37 שניות, 9:16 אנכי, ללא דיבור) בסגנון פיקסאר תלת-ממד, מיוצר ב-Seedance 2.0.

**הסיפור:** מהנדס לוויינים בתע"א שקוע עד מעל הראש בעבודה, מסתכל בשעון ומבין שהוא חייב לרוץ. בדרך החוצה הוא עובר ליד דוכן פרחים שהוקם בקמפוס לכבוד ט"ו באב, מסתכל בשעון וממהר — מוותר על פרחים לאשתו. נתקע בפקקים באיילון ומתעצבן. מגיע הביתה בידיים ריקות, אשתו שציפתה להפתעה נשברת — והוא מסיים את ט"ו באב ישן כפיות עם הכלב במלונה.

## מבנה

- `refs/` — תמונות הרפרנס (קרקטר-שיטים ולוקיישנים בסגנון פיקסאר)
- `prompts/ref-image-prompts.md` — פרומפטים ליצירת רפרנסים חסרים (אישה, בית+מלונה+כלב)
- `prompts/satellite-hall-location-prompt.md` — פרומפט ללוקיישן אולם הלוויינים + חדר הבקרה
- `prompts/ayalon-location-prompt.md` — פרומפט ללוקיישן האיילון מתוך צילום אמיתי
- `prompts/seedance-gen0.txt` — ג'נרציה 0: הלחץ במשרד (~8 שניות)
- `prompts/seedance-gen1.txt` — ג'נרציה 1: הדוכן בקמפוס (~10 שניות)
- `prompts/seedance-gen2.txt` — ג'נרציה 2: פקקים באיילון (~9 שניות)
- `prompts/seedance-gen3.txt` — ג'נרציה 3: הדלת והמלונה (~10 שניות)

## שיטת העבודה (Seedance 2.0)

כל ג'נרציה היא בקשה עצמאית: בלוקי נעילת `@ImageN` + בלוק STYLE & TECHNICAL חוזרים מילה-במילה בראש כל ג'נרציה, ומספרי ה-`@ImageN` תואמים את סדר תמונות הרפרנס המוצמדות לאותה ג'נרציה. שוטים של 1–3 שניות, מצלמה קודם, פעולה קונקרטית, מעבר מפורש בסוף כל שוט. שלושת הקליפים מחוברים ב-ffmpeg לקובץ סופי אחד.

פרמטרים: `seedance_2_0`, mode=std, resolution=1080p, aspect_ratio=9:16, genre=comedy, generate_audio=true (סאונד טבעי בלבד — בלי מוזיקה, בלי דיבור).
