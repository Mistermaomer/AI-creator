# Vault Library — 150 ready Seedance 2 setups

Source: "EL COLOGNE — Prompt Vault" (Seedance 2.0-compatible prompt library by
el_cologne, provided by the user). Prompts are kept verbatim as adaptable
setups: replace the bracketed placeholders (`[SUBJECT]`, `[CHARACTER]`,
`[PRODUCT]`, `[ARTIST]`, `[PILOT]`, `[FIGHTER]`, …) and lift whole sentences or
devices freely into house-format shots. The craft rules distilled from this
library live in `vault-lessons.md` — read that first; use this file as a lookup
of proven setups when a brief matches a category.

**AVOID key** — negative prompt to pair with the setup (paste into Seedance's
negative field):
- *(none)* — no negative needed (static camera / no character-motion risk).
- **BASE** = `deformed bodies, extra limbs, morphing characters, warped faces, stutter-stepping, sliding feet, clipping through objects, floating weightless drift, on-screen text, watermarks, subtitles`
- **BASE +x** = BASE plus the listed extension terms.
