# Character Sheets — the young couple (1962)

Identity-locking sheets for the two leads of the "Same Taste. Same Love." film,
built per the platform's character-sheet workflow: `photoreal-unretouched` preset,
one subject per sheet, turnaround + expression sheet per character.

**Why these compositions:** the film is a 360° orbit — the camera sees each lead
from the front, in profile and **from behind** (where the era transition happens),
so the turnaround's back view is not optional here. The expression sheets encode
each lead's signature laugh beats from the film so future generations can quote
them exactly.

**Usage:**
- Aspect ratio **16:9** (or 3:2) for all four sheets.
- Optionally attach the young-couple diner image as a *face/style reference* when
  generating, so the faces lock to the film's couple; the prompts stand alone too.
- Below-the-table wardrobe (her skirt/shoes, his jeans/shoes) is invisible in the
  diner frame, so it's defined here as period-correct 1962 pieces — swap freely,
  then keep the choice locked everywhere.
- **Aged sheets come next** and must reuse these slots verbatim, changing only the
  age markers and hair color (white) — same cardigan, same jacket, same everything.
  That sameness is the film's gimmick.
