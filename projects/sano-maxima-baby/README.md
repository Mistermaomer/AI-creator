# קמפיין: סנו מקסימה BABY — פרסומת AI

## המוצר

**סנו מקסימה BABY — ג'ל + מרכך** לכביסה: היפואלרגני, בתוספת תמצית שיבולת שועל, לבגדי תינוקות ובעלי עור רגיש. 2 ליטר / 40 כביסות. הושק בקמפיין **"בשעה טובה! נולד BABY חדש על המדף"**.

## הקונספט הנבחר — "הבהלה אל המדף"

הוק מתח של לידה שתופס את העין בשניות הראשונות: בהלת חדר לידה מלאה — צוות רפואי דוחף אלונקה בריצה במסדרון בית חולים — ובדחיפה דרך הדלתות האחרונות המסדרון מתמזג במורף רציף אחד למעבר הכביסה בסופר. הצוות "מיילד" את הבקבוק העטוף בבד טטרה אל מדף מואר בספוט, כמו הצגת יילוד. מתח → הקלה → "בשעה טובה!".

**היתרון של AI על צילום רגיל:** שוט רציף שבו קירות בית חולים נמסים למדפי סופרמרקט תוך כדי ריצה, POV של "המטופלת" (שמתגלה כבקבוק), ופתיתי שיבולת שועל שצפים כמו שלג — בלתי אפשרי להפקה מצולמת.
