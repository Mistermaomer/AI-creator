# ערכת סאונד ElevenLabs — "הבהלה אל המדף" · סנו מקסימה BABY

שלושה כלים: **Text to Speech** (דיאלוג בעברית — מודל Eleven v3 לתגי רגש, או Multilingual v2), **Sound Effects** (פרומפטים באנגלית), **Music** (שיר הערש). כל שכבה מופקת בנפרד ומורכבת ב-CapCut לפי מפת המיקס בסוף.

---

## 1) דיאלוג בעברית (Text to Speech)

קול מומלץ למיילדת: אישה, שנות ה-40, חם וסמכותי. Settings: Stability ~35% (רגש גבוה), Similarity ~80%. במודל v3 תגי הרגש בסוגריים עובדים; ב-Multilingual v2 למחוק אותם ולסמוך על הפיסוק.

**שורה 1 — הצעקה בריצה (שוט 1A, מחליפה את האנגלית):**
```
[shouting joyfully, out of breath] היא בדרך!! פנו את המסדרון!!
```

**שורה 2 — אחות שנייה בריצה (שוט 1B/1C, אופציונלי):**
```
[excited, breathless] תתכוננו!! עוד רגע היא פה!!
```

**שורה 3 — הלחישה בעצירה (שוט 2C):**
```
[hushed, moved, almost whispering] הנה היא... תראו אותה...
```

**שורה 4 — רגע החשיפה (שוט 3B):**
```
[soft gasp, tearful joy] מזל טוב...
```

**שורה 5 — קריינות מותג סוגרת (על 3B-3C, קול קריין/ת חם):**
```
[warm, tender narration] בשעה טובה! נולד BABY חדש על המדף. מקסימה BABY של סנו — ג'ל ומרכך היפואלרגני, עם תמצית שיבולת שועל. לכביסה הכי עדינה שיש.
```

טיפ: להפיק כל שורה בנפרד (לא בקובץ אחד) כדי לשלוט בתזמון; לצעקה — להפיק 3-4 טייקים ולבחור.

## 3) שיר הערש (Music)

```
A gentle music box lullaby, slow and tender celeste melody, warm and intimate, like a nursery mobile turning, gradually blooming with soft strings, resolving peacefully — 20 seconds
```
נכנס ב-12~ ומתגבר בהדרגה עד הסוף; ברגע האחרון (פעימת הלב) — מנמיכים אותו לאפס.

## 4) מפת מיקס (CapCut)

| זמן | שכבות |
|---|---|
| 0-2 | מוניטור מהיר + אלונקה + דלת #1 |
| 2-4 | + הצעקה "היא בדרך!!" (שורה 1) |
| 4-9 | + סניקרס + אינפוזיה + שורה 2 + דלת #2 |
| 10-12 | דלת #3 (חזקה) + וווש סלואו-מושן + מוניטור מתחיל להאט |
| 12-18 | שיר ערש נכנס עדין + אווירת סופר + מוניטור נמוג |
| 18-20 | לחישה "הנה היא..." (שורה 3) |
| 20-23 | בכי לידה ראשון (#8) + נצנוץ (#12) |
| 23-26 | בכי→צחקוק (#9) + "מזל טוב..." (שורה 4) + קריינות מותג מתחילה |
| 26-29 | מחיאות כפיים (#10) + קריינות ממשיכה |
| 29-30 | הכל נמוג → פעימת לב אחת (#11) → שקט |

**העיקרון:** הבכי הראשון נוחת בדיוק על רגע פתיחת החיתול (3B) — זו ה"לידה"; והוא חייב להפוך לצחקוק תוך 2-3 שניות כדי להישאר בטון השמח.
